Yahu-ai

Real-time taxi booking app for customers with driver tracking, route optimization, and seamless user experience.

About the Project

Yahu-ai is a consumer-facing mobile application designed to provide a smooth and reliable taxi booking experience in real time. Built with Flutter for both Android and iOS, the app communicates with a Laravel backend using WebSockets to stream live driver locations and trip updates. Users can request a ride, track the driver's approach, and review past trips. The interface emphasizes simplicity, speed, and clear feedback.

Tools & Technologies

  • Flutter
  • GetX
  • Google Maps API
  • WebSocket
  • Laravel (PHP)
  • MySQL
  • Git

Key Features

  • Real‑time GPS tracking for drivers and passengers
  • Interactive map with route visualization
  • WebSocket integration for live updates
  • Trip state management and history
  • Customer ratings and feedback
  • Location‑based notifications

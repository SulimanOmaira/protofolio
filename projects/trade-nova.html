Trade Nova

Lightweight mobile accounting & POS for small stores with store & inventory management.

About the Project

Trade Nova is an offline‑first point-of-sale and inventory management app tailored for small retail shops. Written in Flutter, it stores data locally using SQLite and syncs with a Laravel backend when Internet is available. The design focuses on speed and usability in low‑connectivity environments, providing barcode scanning, customer tracking, and simple financial reports.

Tools & Technologies

  • Flutter
  • SQLite
  • Firebase
  • Laravel Backend
  • Git

Key Features

  • Store and inventory management with categories
  • Full offline‑first operation with local database
  • Cloud sync when connection is available
  • Sales reports and analytics dashboard
  • Barcode scanning for quick checkout
  • Customer profiles and history tracking

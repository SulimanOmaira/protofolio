Yahu Driver

Driver companion app for taxi coordination with earnings dashboard and real-time notifications.

About the Project

Yahu Driver is the counterpart application for taxi drivers, offering a powerful yet easy-to-use interface to manage trips and monitor earnings. Developed in Flutter with GetX state management, the app connects via WebSocket to the same Laravel backend used by the customer app. Drivers can accept or decline rides, view navigation instructions, and check their revenue in real time. Offline support ensures route guidance continues when the network drops.

Tools & Technologies

  • Flutter
  • GetX
  • Firebase (for notifications)
  • WebSocket
  • Google Maps API
  • Laravel
  • SQLite (offline storage)
  • Git

Key Features

  • GPS tracking and turn-by-turn navigation
  • Earnings dashboard with daily/weekly reports
  • Real-time trip notifications and alerts
  • Trip management (accept, cancel, history)
  • Driver rating and feedback system
  • Offline route guidance when connectivity is poor

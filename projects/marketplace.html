Car For You (CFY)

Car marketplace for buying/selling with integrated chat, AI n8n chatbot, and recommendation system.

About the Project

CFY (Car For You) is a lightweight marketplace application designed to connect buyers and sellers of vehicles across the region. The mobile front-end is built with Flutter, while the backend uses Laravel and MySQL. A custom recommendation system offers users tailored suggestions based on browsing history. Core functionality includes real‑time chat (WebSocket) and an AI‑driven chatbot implemented with n8n to assist with queries and onboarding.

Tools & Technologies

  • Flutter
  • Laravel
  • MySQL
  • WebSocket
  • Firebase
  • n8n (AI chatbot)
  • Git

Key Features

  • Advanced search and filtering for listings
  • Real-time chat between buyers and sellers
  • Integrated AI chatbot powered by n8n
  • Simple recommendation engine based on preferences
  • Image gallery with pinch‑to‑zoom
  • Secure in‑app transaction flow
